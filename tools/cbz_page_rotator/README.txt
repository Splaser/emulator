CBZ 单页旋转校正（Windows 独立工具）

双击 CBZPageRotator.exe，打开或拖入转换好的 CBZ。
按页码跳转，使用左转 90°、180°、右转 90°查看效果。
“撤销本页”撤销当前页面尚未保存的旋转。
点击“保存 · 直接替换”直接修改当前 CBZ，不保留备份。
可先改多页，再一次保存；关闭时会提示处理未保存的修改。

页码按照图片文件名的自然顺序排列，包含封面。

JPG、PNG、BMP 支持旋转；其他图片格式若不能解码，会提示无法预览。
未修改条目的内容字节、名称、顺序、时间和外部属性保留。
修改过的 JPG 使用质量 98 重新编码；PNG/BMP 保存旋转后的像素。
ZIP 容器会重建，容器压缩方式/注释/额外字段不保证保留，压缩包大小可能变化。
不使用 OCR，不上传文件，不读取图片中的文字指令。

保存先在原文件同目录完成临时 CBZ，刷盘后替换原文件，不使用先删除再写入。
失败时清理临时文件；不会生成 .bak 或复制一份原 CBZ。
如果文件被其他软件替换，拒绝覆盖，请重新打开。
保存后无法用工具撤销已写入的旋转，可手动反向旋转再保存。

无需 Python 或额外安装依赖；需要 Windows .NET Framework 4.7.2 或更高版本。
源码：CBZPageRotator.cs；双击编译：build.bat；命令行构建：build.cmd。
验证源码：RotatorTests.cs；不涉及原书修改。
运行 test.cmd 可执行临时漫画包上的自动验证，测试结束自动清理测试漫画。
可选界面验证：test.cmd "漫画.cbz的完整路径" "预览.png的完整路径"。
界面验证只预览第七页右转 90° 的效果，不保存漫画。

此目录可独立使用，不接入模拟器构建。
Git 仅同步源码、说明和脚本；exe、默认 preview.png 和临时文件已忽略。
